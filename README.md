# mcclelland.info

Source for [mcclelland.info](https://mcclelland.info): the professional site of a product leader working on AI-native transformation.

## What's here

| Path | Page |
|---|---|
| `index.html` | Home |
| `work/` | Work and case studies, with downloadable PDFs in `case-studies/` |
| `method/` | How the work is approached |
| `writing/` | Writing (RSS at `feed.xml`) |
| `about/` | About |
| `teaching/` | Teaching and AI mentoring |

## How it's built

- Plain static HTML and CSS (`assets/`), with no build step or framework.
- Published with GitHub Pages from `main`, on the custom domain set in `CNAME`. `.nojekyll` turns off Jekyll processing.
- Changes go to a preview branch and are merged by pull request after review.
